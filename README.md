# Quản lý Bán hàng Mini App
> Đồ án môn học: Mô hình phát triển phần mềm Agile

## Giới thiệu
Dự án phát triển ứng dụng quản lý bán hàng Mini App, áp dụng quy trình Scrum để quản lý tiến độ và chất lượng sản phẩm.

## Cấu trúc thư mục
- `.github/`: Chứa template cho Issue và Pull Request theo chuẩn Scrum.
- `docs/agile/`: Tài liệu quản lý dự án (Product Backlog, Sprint Planning, Daily Standups, Review, Retro).
- `src/`: Thư mục chứa mã nguồn của ứng dụng.
